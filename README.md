# DP Flooring Services LLC — website

Static, dependency-free marketing site for **DP Flooring Services LLC**
(Drayton Potthast & Dylan Pierson) — epoxy flooring across Champaign County,
Bloomington-Normal and 50+ miles of Central Illinois.

- **28 pages**: home, services hub + 6 service pages, 13 location pages, about,
  service area, gallery, FAQ, contact, thank-you, 404
- No framework, no build step at deploy time, no runtime JavaScript dependency
- Total page weight is dominated by photos; the CSS is ~40 KB and the JS ~6 KB

---

## 1. How to work on it

**Every `.html` file in this repo is generated.** Do not hand-edit them — the next
build overwrites your changes. Edit one of these three instead:

| To change | Edit |
| --- | --- |
| Phone, email, owners, service-area towns, social links, prices, base URL | `site.config.json` |
| Any page copy, page structure, a new page | `tools/build.py` |
| Design, layout, colors | `assets/css/styles.css` |

Then rebuild and preview:

```bash
python3 tools/build.py .          # regenerates all 28 pages + sitemap.xml + robots.txt
python3 -m http.server 8000       # then open http://localhost:8000
```

`python3 -m http.server` matters: the site uses root-relative paths (`/assets/...`),
so opening `index.html` straight off the disk with `file://` will not load the CSS.

Requires Python 3 only. No pip installs.

## 2. The SEO structure

### XML sitemap — automatic

`sitemap.xml` is regenerated by `tools/build.py` on every run, from the same page
registry that writes the HTML. **Add a page to `build_pages()` and it is in the
sitemap** — there is no second list to keep in sync, and no way to add a page and
forget it. `/contact/thank-you/` and `/404.html` are deliberately excluded and
carry `noindex`.

`robots.txt` is generated alongside it and points at the sitemap.

**Submit it once, after the domain is live:**

1. **Google Search Console** → <https://search.google.com/search-console>
   - Add a property. Prefer the **Domain** property type and verify with the DNS
     TXT record — that covers `http`, `https`, apex and `www` in one go.
   - Sitemaps → enter `sitemap.xml` → Submit.
   - Then URL Inspection → paste the homepage → *Request indexing*. Do the same
     for `/services/` and your two or three highest-value location pages. This
     is the fastest route into the index for a brand-new domain.
2. **Bing Webmaster Tools** → <https://www.bing.com/webmasters>
   - Fastest path is *Import from Google Search Console*, which carries the
     verification and the sitemap across in one click.
   - Otherwise: add the site, verify by DNS, then Sitemaps → Submit
     `https://www.dpflooringservices.com/sitemap.xml`.

You only submit once. Both engines re-crawl the sitemap on their own after that,
so a redeploy with new pages needs no further action.

### Location pages

One page per city, at the `/[service]-[city]/` URL format:

```
/epoxy-flooring-champaign-il/        /epoxy-flooring-bloomington-il/
/epoxy-flooring-urbana-il/           /epoxy-flooring-normal-il/
/epoxy-flooring-savoy-il/            /epoxy-flooring-decatur-il/
/epoxy-flooring-mahomet-il/          /epoxy-flooring-danville-il/
/epoxy-flooring-rantoul-il/          /epoxy-flooring-monticello-il/
                                     /epoxy-flooring-tuscola-il/
/garage-floor-coating-champaign-il/  /garage-floor-coating-bloomington-il/
```

Each one carries a unique title tag, a unique meta description, the city in the
`<h1>`, the city in the opening paragraph, the city in at least one image `alt`,
an embedded Google Map centered on that city, `Service` + `LocalBusiness` schema
with `areaServed` set to that city and county, and — most importantly — a
**genuinely different body section** describing what the concrete is actually
like in that town. The build refuses nothing, but the audit in §5 will flag you
if two pages ever end up with the same title, description or H1.

> **One judgement call worth knowing about.** The brief asked for a page per
> service *per* city. Six services × 40 towns is 240 near-identical pages, which
> is the textbook definition of a doorway-page network and is the single most
> reliable way to get a local site filtered out of the results. So this ships
> with 13 pages that each say something true and specific instead: the 11
> headline towns on the primary service, plus dedicated pages for the two exact
> keyword phrases you named (`garage floor coating Bloomington IL`,
> `garage floor coating Champaign IL`). Adding more is a five-line change in
> `LOCATIONS` — the constraint is not the code, it is having something distinct
> to say about each town. Say the word and I'll write more.

**To add a city:** append a dict to `LOCATIONS` in `tools/build.py` and rebuild.
Write real copy for `intro` and `local` — if it could be find-and-replaced with
another town's name, it is not worth publishing.

### Service pages

One page per service, each with its own H1, title and description, a
before/after slider, a pricing panel, and internal links out to the location
pages:

```
/services/garage-epoxy-floors/                  /services/shop-warehouse-floors/
/services/basement-floors/                      /services/decorative-flake-and-metallic-epoxy/
/services/commercial-industrial-coatings/       /services/floor-prep-and-repair/
```

`/services/` remains as a hub that links to all six.

**Pricing.** Every service page ships with a "what moves the price" panel plus a
quote CTA, because I don't know your real numbers and inventing them would have
been worse than useless. When you're ready to publish ranges, put them in the
`pricing` block of `site.config.json`:

```json
"pricing": { "garage-epoxy-floors": "$4.50 – $7.00 / sq ft" }
```

The page then leads with that figure instead. Leave a value as `""` to keep the
cost-drivers version.

### Internal linking

Home → service pages → location pages → back to service pages, with the service
area hub linking every location page and every location page linking all six
services plus nine sibling towns. There are no orphan pages; §5 verifies that.

## 3. Technical basics

**Speed.** All 22 photos are cropped to their display slot and re-encoded as
progressive JPEG at quality 74–86 — 4.3 MB across the whole library, versus
~40 MB for the originals. Every `<img>` carries explicit `width`/`height` (so
nothing shifts as the page loads), `loading="lazy"` below the fold, and
`decoding="async"`. The hero is `fetchpriority="high"` with a 1280/2400 `srcset`
so phones don't pull the desktop file. No jQuery, no plugins, no trackers, no
web fonts beyond two Google families loaded with `display=swap`.

**Mobile-first.** Every layout starts single-column and adds columns at
breakpoints. Phones also get a fixed bottom bar with **Call Now** and
**Free Quote** that follows you down every page — the one thing that matters most
when somebody is standing in a garage with a phone in their hand. All phone
numbers are `tel:` links, and `format-detection` is on.

**SSL / HTTPS.** Netlify issues and renews a Let's Encrypt certificate
automatically once DNS points at it — nothing to buy. `netlify.toml` sets
`Strict-Transport-Security`, plus `X-Content-Type-Options`, `X-Frame-Options`
and a `Referrer-Policy`. **Turn HSTS on only after the certificate is live**;
enabling it early makes the site unreachable until DNS resolves. The commented
apex→www redirect in `netlify.toml` should be uncommented at the same time so
link equity lands on one hostname.

**Google Business Profile + NAP.** The name, phone and locality are written once
in `site.config.json` and rendered from that single source into the footer, the
header, the contact page and the `LocalBusiness` JSON-LD — so they cannot drift
apart. To finish the job:

1. Create the profile as a **service-area business** (you travel to customers),
   which hides the street address and instead lists the towns you serve.
2. Make the profile match `site.config.json` **character for character**:
   `DP Flooring Services LLC` and `(217) 417-5950`. Not "DP Flooring", not
   "217-417-5950". Inconsistent NAP is the most common reason a local business
   fails to rank for its own name.
3. Set the profile's service areas from the `serviceArea.groups` list.
4. Paste the profile's share link into `social.googleBusinessProfile` in
   `site.config.json` and rebuild — it then appears in the footer and in the
   `sameAs` array of the LocalBusiness schema, which is what ties the site and
   the profile together in Google's eyes.

## 4. The quote form

`/contact/` posts to **Netlify Forms** (`data-netlify="true"`, honeypot field,
redirect to `/contact/thank-you/`). It needs no backend and no API key, but it
**only works when hosted on Netlify** — the form will silently do nothing
anywhere else.

Fields: name, phone, email, job address, floor type, approximate square footage,
message. Client-side validation and US phone formatting are progressive
enhancements; the form still submits with JavaScript off.

After the first deploy, go to **Netlify → Forms → quote → Settings → Form
notifications** and add an email notification to `dpflooringservicesllc@gmail.com`,
or submissions will pile up in the dashboard unseen.

**Hosting somewhere else?** Set `form.provider` to anything other than
`"netlify"` in `site.config.json` (which strips the Netlify attributes), then in
`tools/build.py` change the form's `action` to your endpoint:

- **Formspree** — `action="https://formspree.io/f/YOUR_ID"`, add
  `<input type="hidden" name="_next" value="https://.../contact/thank-you/">`
- **FormSubmit** — `action="https://formsubmit.co/dpflooringservicesllc@gmail.com"`

## 5. Verifying a build

```bash
python3 tools/build.py . && python3 tools/audit.py .
```

`tools/audit.py` fails loudly on: a missing title, description or canonical; a
page with zero or two `<h1>`s; a title over 70 characters or a description
outside 110–175; **any duplicate title, description or H1 across pages**; an
`<img>` with no `alt`; invalid JSON-LD; a broken internal link; a missing image;
an unrendered template placeholder; and any page not reachable from the sitemap.
Run it before every deploy.

## 6. Before launch — the short list

- [ ] Set the real domain in `site.config.json` → `baseUrl`, rebuild
- [ ] Point DNS at the host; confirm the certificate is live; **then** uncomment
      the apex→www redirect in `netlify.toml`
- [ ] Real Facebook / Instagram URLs in `site.config.json` → `social`
      (the two currently there are **guesses** — set them to `""` to remove the
      icons entirely rather than shipping links that 404)
- [ ] Create the Google Business Profile, then paste its link into
      `social.googleBusinessProfile`
- [ ] Turn on Netlify form notifications
- [ ] Submit the sitemap to Search Console and Bing (§2)
- [ ] Swap in real job photos as they come — see
      `assets/img/PHOTO-CREDITS.md` for the priority order and the aspect ratios
- [ ] Optional: add real price ranges to `site.config.json` → `pricing`
